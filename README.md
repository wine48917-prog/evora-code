🍷 EVORA CODE

A Modern Web Development Studio

EVORA CODE is a modern online coding environment designed to make web development easier, faster, and more organized.

Build your projects, write your code, and preview your results in one workspace.

---

✨ Features

- 💻 Advanced Code Editor powered by Monaco Editor.
- 📁 File Explorer for managing project files.
- 🌐 Live Preview for HTML, CSS, and JavaScript.
- 🎨 Modern Black & Burgundy Interface.
- 📑 Multiple Editor Tabs.
- 💾 Local Auto Save.
- 📦 Export Projects as ZIP.
- 📱 Responsive Preview for Desktop, Tablet, and Mobile.
- 🛠️ Output Panel.

🧑‍💻 Supported Languages

- HTML
- CSS
- JavaScript
- JSON

🚀 Getting Started

Requirements

- Node.js
- npm

Installation

git clone YOUR_REPOSITORY_URL
cd evora-code
npm install
npm run dev

Open the local development URL provided by Vite.

🏗️ Build

npm run build
